Standards axis, non-blocking findings:

1. apps/bridge/cells/host.mjs:27 contains literal bidirectional control characters (U+200E, U+200F, U+202A to U+202E, U+2066 to U+2069) inside the regex class. Behaviour is right, but invisible characters in source are a Trojan-Source smell and unreadable in review. Write them as `‎‏‪-‮⁦-⁩`. Developer cleanup; security may want to see it.
2. host.mjs:113-114: `run.finally(...)` creates a derived promise with no handler. If `spawnAgent` ever throws (for example `onChange` throws inside `publish`), that is an unhandled rejection, which the installed uncaughtException handler turns into a shutdown and exit 1. Low likelihood; a `.catch` on the derived promise would be safer.
3. host.mjs:249: `shutdown()` awaits every pending spawn. A runtime whose `spawn()` never resolves would hang shutdown and so SIGINT handling. The fake and the future real adapter resolve, so this is a hardening note for D2.
4. host.mjs:25-29 `clean()` strips C0/C1 and bidi controls but not zero-width characters (U+200B to U+200D, U+2060) or U+061C. Cosmetic spoofing only; the secret mask and length cap are in place.

Also seen and fine: signal handlers end with `process.exit(128+n)` after shutdown, installed only when a runtime is given, and removed in `close()`.
