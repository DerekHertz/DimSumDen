## Notes for the developer

- The probe `host-shutdown-probe.mjs` is a test fixture (not `*.test.mjs`); it calls `startBridge({ root, port: 0, auth, runtime, policy: { killGraceMs: 100 } })` and `bridge.host.start`, and installs nothing itself.
- Fake runtime options: spawnDelayMs, stdinCloseEnds, sigtermEnds, sigkillEnds, failSpawn (mutable at `runtime.config`); records at `runtime.spawns[i]` with `args`, `calls`, `exited`, `emit`, `exit`; `runtime.peakLive`.
- Agent id pattern the tests accept: `^[a-z]-[0-9a-f]{16}$` (ADR examples use `c-`; approvals use `a-`, so pick one for agents and keep it distinct from approvals).
